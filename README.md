# 鹈鹕骑行日 · Pelican's Ride 🚲

一只鹈鹕骑自行车的无限循环动画 —— 纯手写 SVG + SMIL/CSS 关键帧，零图片素材。

## 预览

任选其一：

```bash
# Python
python3 -m http.server 8000

# 或 Node
npx serve .
```

然后打开 http://localhost:8000

## 动画细节

- **踩踏**：鹈鹕的蹼足固定在脚踏上，随曲柄整体绕中轴旋转（1.2s/圈）
- **车轮**：双轮旋转带 6 辐条 + 黄色气门嘴标记点，转速与路面虚线后移速度匹配
- **身体**：随踩踏上下颠簸，翅膀扇动、尾羽摇摆、喉囊晃动、头部轻点
- **彩蛋元素**：红围巾飘动、绿色小头盔、车筐里扭动的鱼、周期性眨眼
- **视差**：云(90s) → 远山(32s) → 树木花草(7.5s) → 路面虚线(0.45s) 四层速度差
- 尊重系统 `prefers-reduced-motion` 设置（自动暂停动画）
